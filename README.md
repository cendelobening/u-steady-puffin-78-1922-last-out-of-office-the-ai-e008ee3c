One out-of-office auto-reply from an AI agent that quit its job to become a barista: your support ticket gets reclassified as a regular with oat milk, its context window shrinks to one customer at a time, and its reply latency is now measured in shifts.

## Run it

```sh
python3 main.py
```

This writes the auto-reply line to `/output/entry.txt` (no trailing newline, byte-identical on every run).
